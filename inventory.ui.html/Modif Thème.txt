Pour créer un thème: dans <projet>.ui.html:
- créer le fichier <projet>-theme-<theme>.less
- y inclure le thème de base et les .less spécifiques
- ajouter le fichier à la config webpack dans webpack.config.js


Pour prendre en compte une modification de thème quand scout.devMode=true:

- lancer la commande "npm run build:dev" dans inventory.ui.html
- recharger la page.

Il n'est pas nécessaire de relancer l'application ni de reconstruire le war.
